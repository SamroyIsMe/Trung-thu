# Trung Thu của bạn

Website quiz giao diện Trung Thu: người dùng trả lời vài câu hỏi cơ bản (rước đèn, bánh, phá cỗ, ngắm trăng) rồi nhận một “phong cách đêm rằm” vui.

## Công nghệ

- Next.js (App Router)
- Tailwind CSS
- Material UI

## Chạy local

```bash
npm install
npm run dev
```

Mở [http://localhost:3000](http://localhost:3000).
